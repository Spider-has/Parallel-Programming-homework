# Передача данных через анонимные каналы. Домашняя работа параллельное программирование

Программа для межпроцессного взаимодействия (IPC) в POSIX-системах. Передает текст произвольного размера из родительского процесса в дочерний.

utils.hpp / utils.cpp — общие утилиты: RAII-обертка FileDescriptor и функции надежной поблочной передачи данных (sendBytes, captureBytes).

main.cpp — родительский процесс: создает pipe, делает fork, подменяет потомка через execl и транслирует данные из stdin.

child.cpp — дочерний процесс: восстанавливает файловый дескриптор из аргументов, вычитывает данные из трубы и печатает их в stdout.

parent_bin / child_bin — готовые бинарники (результат сборки).

README.md — документация проекта.

a.out — временный артефакт компиляции по умолчанию (можно безопасно удалить).
